## Roadmap

1. **Verify a fresh sensor reading over serial.** Send a request with an identifier to the ESP32 example and check the response against that identifier. Record a pass only when the requested reading arrives within the timeout.
2. **Write a Raspberry Pi Pico guide.** Start with the original RP2040 Pico. Cover board identification, the official pinout, BOOTSEL and UF2 flashing, and a check that confirms the example firmware is running.
3. **Estimate prototype cost and battery runtime.** Use editable assumptions for component costs, capacity, active and sleep current, and duty cycle. Show which assumptions drive the estimate.
